# 出品フォト

スマホで2〜5枚の商品写真を正方形の1枚に結合する、React + TypeScript + Viteの静的PWAです。広告・会員登録・バックエンドはありません。写真はブラウザ内のCanvasで処理し、アップロードや解析用の外部通信は行いません。フォントも端末のものを使用します。

## 開発

Node.js 22以上を推奨（この環境では24で検証）。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

既存のチェックアウトを使用できます。追加のworktreeは不要です。

## 操作

1. 写真を2〜5枚まとめて選択。最初のレイアウトを自動適用します。
2. 必要に応じてレイアウトをタップし、写真を直接ドラッグ・2本指で拡大縮小します。下のサムネイルを選択すると差し替え、左右ボタンによる並び替え、削除、倍率スライダー・リセットが使えます。
3. 背景（白・黒・グレー）、余白、角丸を調整し、画面下部の「画像を保存」を押します。
4. 完成画像の共有ボタンからiPhoneの「画像を保存」を選択します。共有非対応の場合はJPEGダウンロード、または完成画像の長押しで保存してください。

出力は2000×2000px・JPEG（品質0.95）。写真は枠を埋めるように中央で切り抜かれます。色補正・美肌・ロゴ除去などの自動加工は行いません。ただしCanvas/JPEG変換による再圧縮・色空間の変換は発生します。余白と角丸のpx表示は出力画像基準です。倍率は1〜6倍。レイアウト変更は全写真の位置と倍率をリセットし、並び替え時は写真の調整値を引き継ぎます。

対応レイアウト：2枚（上下、左右）、3枚（上1＋下2、左1＋右2、縦3分割、横3分割）、4枚（2×2、上1＋下3）、5枚（上2＋下3、上3＋下2、上1＋下4）。

ブラウザがデコードできる画像に対応します。HEIC対応はOS・ブラウザに依存します。読み込めない場合はJPEG/PNGで選び直してください。写真・編集状態は永続保存しません。リロード・終了時に消えます。大きな写真を複数選んだ場合のメモリ制限は端末に依存します。

## PWA

HTTPSで一度アクセス後、iPhone Safariの共有メニューから「ホーム画面に追加」でインストールできます。Androidはブラウザのインストールメニューを利用します。Service Workerは同一オリジンのアプリ資源のみをキャッシュします。最初のオンライン読込完了後はオフラインで使用できます。写真のblob URLはキャッシュしません。更新時はオンラインでアプリを再読み込みしてください。キャッシュには写真は残りません。

## GitHub Pagesへの公開

`.github/workflows/pages.yml` を同梱しています。

1. このコードをGitHubの `main` ブランチにpushします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
3. **Actions → Deploy to GitHub Pages** を実行（mainへのpushでも実行）します。
4. deploy完了後、Pagesに表示されるURLから利用します。

Viteの `base: './'` と相対manifest/SWパスにより、`/shuppin-photo/` 配下と独自ドメインの両方に対応します。ビルド成果物は `dist/`。この作業ではGitHubへのpushや公開は実施していません。

## 検証

```sh
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
# システムにChromiumがある環境の場合
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

単体テストは全11レイアウトの領域数・境界・重なり、余白なしの面積、拡大・移動時の画像のはみ出し制限を確認します。E2Eは390px幅のChromiumで写真読込・レイアウト変更・差し替え・並び替え・編集・JPEGの寸法と形式・ダウンロード・エラー表示・オフライン再読込を確認します。

実行結果および実機チェック項目は [TESTING.md](TESTING.md) を参照してください。
